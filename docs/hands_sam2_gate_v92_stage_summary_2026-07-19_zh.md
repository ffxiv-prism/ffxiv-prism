# HANDS SAM2 一致性门控 v92 阶段总结（2026-07-19）

## 结论

本阶段验证了“原始 HANDS 裁剪为主干，SAM2 前景裁剪只在强一致时改写
Top-1”的保守方案。策略只在 fold1 调参并冻结，fold2/3 不再调参。

三折合计 945 个物品不相交样本上，冻结门控把 Appearance Top-1 从
`20/945 = 2.116%` 提升到 `21/945 = 2.222%`；Top-10、Top-100 和
Top-1000 分别保持 `83/945`、`337/945`、`863/945` 不变，性别与种族
分组均无命中回退。该结果证明 SAM2 有少量互补信息，但只增加 1 个
Top-1 命中，不足以抵偿 demo 推理时额外加载并运行 SAM2 的显著延迟与显存开销。

因此：保留 v92 为可复核实验分支，不接入默认推理。生产 HANDS 继续使用
DINOv2 qv71 v5 多尺度候选路由、性别路由和 crop RRF(`k=1`) 基线。

## 冻结策略

- SAM2 分支权重：`0.25`；
- 最终候选池：仅由原始主干冻结，SAM2 不能改变深层候选覆盖；
- 只有原始主干候选排名 `<=3`、SAM2 候选排名 `<=3`，且
  `SAM2_rank / base_rank >= 1.0` 时才允许改写；
- 评价截断：Top-1 / Top-10 / Top-100 / Top-1000；
- fold1 选择策略，fold2/3 仅验证。

## SAM2 掩码质量与失败保护

| fold | 样本 / 裁剪 | SAM IoU 中位数 | IoU < 0.5 |
|---|---:|---:|---:|
| 1 | 325 / 1625 | 0.766 | 208 |
| 2 | 326 / 1630 | 0.748 | 231 |
| 3 | 325 / 1625 | 0.750 | 249 |

SAM2 单分支的三折命中分别为：

- fold1：`2 / 22 / 79 / 252`；
- fold2：`7 / 18 / 65 / 261`；
- fold3：`9 / 22 / 100 / 286`。

低 IoU 样本中存在手臂或手套主体被掩码切掉的情况，因此不能用 SAM2 裁剪
替换原始裁剪。冻结候选池和强一致门控是必要的失败保护。

# FFXIV Prism 使用说明

上传 FFXIV 单人角色截图，在本地查找头、身体、手、腿、脚的装备外观候选。使用清晰的正面或近正面截图更容易获得有用结果；候选排名需要结合图片人工确认。

## 1. 下载程序和图库

支持 Windows x64，无需安装 Python、Conda 或 Git。首次安装需要联网，完成后可离线使用。

- [下载 Windows 安装包](https://github.com/ffxiv-prism/ffxiv-prism/releases/latest)：选择 `FFXIV-Prism-v0.2.1-windows.zip`，不要选择 Source code。
- [下载装备图库（Google Drive）](https://drive.google.com/drive/folders/1G5N7_xYPplvjrjVKcpQRvAbjZO-2SzcQ?usp=sharing)：选择 `FFXIV-Prism-gallery-20261009.zip`。图库采集日期为 **2026-10-09**。

完整解压 Windows 安装包到短英文路径，例如 `D:\FFXIV-Prism`。安装根目录绝对路径最多 **64 个字符**，包括盘符和分隔符。不要在 ZIP 内运行程序。

将图库 ZIP **原样放入 `imports` 文件夹**，不要解压图库，也不要放入其他 ZIP。文件夹中的 `放置图库ZIP.txt` 无需编辑。

## 2. 安装环境

双击 **安装环境.bat**，选择运行方式：

- **1：CPU**：不需要独立显卡，可使用全部识别功能。
- **2：CPU + GPU**：为兼容的 NVIDIA 显卡额外安装 GPU 环境，同时保留 CPU 环境。请预留至少 **12 GiB** 临时空间。

安装器会先导入图库，再下载和安装依赖、模型，最后进行自检。依赖和模型的下载、安装提示使用英文；下载进度会显示来源、已下载大小、速度和续传状态。看到安装成功提示后，再启动程序。

首次安装如果没有图库 ZIP，会停止并提示放入文件，不会开始下载环境。已经成功导入过图库时，无需再次放入 ZIP。

下载中断时重新运行安装环境即可重试；安装器会复用已有文件，并尽量继续未完成的下载。若某个来源不可用，会尝试其他下载来源。仍然失败时，请按窗口提示检查网络、磁盘空间，或将文件手动下载到提示的位置。

安装成功后，`imports` 中本次使用的 ZIP 和安装下载临时文件会自动清理。`imports` 之外的原始下载、已安装模型和用户报告会保留。

### 稍后启用 GPU

先关闭正在运行的程序，再运行 **安装环境.bat** 并选择 **2**。已有 CPU 环境、模型和图库会复用，无需重新下载图库。

安装器根据 NVIDIA 显卡和驱动选择运行库，不需要单独安装 CUDA Toolkit。显卡或驱动不符合要求时会提示原因；GPU 准备失败后仍可使用 CPU。选择 CPU 不会删除已经安装好的 GPU 环境。

## 3. 识别截图

1. 双击 **启动.bat**，等待启动检查完成。
2. 在浏览器打开窗口显示的地址，通常为 `http://127.0.0.1:8765`。
3. 上传清晰的单人角色截图，开始识别并查看各部位候选。
4. 报告保存在 **`user/reports`**。HTML/JSON 报告可直接保留；生成 PNG 报告需要系统已有 Edge 或 Chrome。

运行期间请保留命令行窗口。使用结束后，在该窗口按 **Ctrl+C** 停止程序。安装或修复前，也应先停止程序。

## 4. 出错时怎么办

| 提示或现象 | 处理方法 |
| --- | --- |
| 缺少内置 Python | 重新下载并完整解压 Windows 安装包 |
| 找不到图库 ZIP | 将配套图库原样放入 `imports`，再运行安装环境 |
| `imports` 中有多个 ZIP | 只保留一个配套图库 ZIP |
| 下载失败 | 检查网络和磁盘空间，重新运行安装环境重试 |
| GPU 不可用 | 先使用 CPU；检查 NVIDIA 驱动后重新安装 GPU 环境 |
| 程序或依赖异常 | 关闭程序，运行 **修复.bat** |
| 图库文件缺失或大小不符 | 重新下载配套图库 ZIP，放入 `imports`，运行安装环境 |
| 窗口提示准备失败 | 必需项检查失败会停止启动，请先处理窗口中指出的问题 |

**修复.bat** 会重新安装依赖，并完整校验模型、程序与图库。普通启动检查文件存在和大小，不会每次对整个图库重新计算哈希。

反馈问题时，请提供错误提示、复现步骤，以及相关日志：

- 安装自检：`work/logs/install-check.log`
- 网页服务：`work/logs/server.log`

可在 [GitHub Issues](https://github.com/ffxiv-prism/ffxiv-prism/issues) 提交问题。

## 下载校验

Release 附件中的 `.sha256` 文件可用于核对下载是否完整。图库 ZIP 的 SHA-256 为：

```text
433eb67ff0a00b60b3690598d038f449e704eb92257f8af74ba15ba844f6e33c
```

在 PowerShell 中运行以下命令，将输出的哈希与上方数值比较（大小写不影响）：

```powershell
Get-FileHash "FFXIV-Prism-gallery-20261009.zip" -Algorithm SHA256
```

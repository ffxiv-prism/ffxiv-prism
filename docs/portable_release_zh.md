# FFXIV Prism v0.2.1 首次正式版

Windows x64 本地装备外观候选检索工具。无需安装 Python、Conda 或 Git。
输入清晰的单人角色截图，返回头、身体、手、腿、脚的装备候选；结果需要人工确认。

## 安装和使用

1. 下载 `FFXIV-Prism-v0.2.1-windows.zip`，完整解压到英文路径，例如 `D:\FFXIV-Prism`。安装根目录绝对路径最多 **64 个字符**（包括盘符和分隔符），不要在 ZIP 内运行。
2. 从维护者网盘下载配套的 `FFXIV-Prism-gallery-20261009.zip`，原样放入 `imports`，该目录只放一个图库 ZIP。请用配套的 `.sha256` 校验文件核对下载。`放置图库ZIP.txt` 是空白占位文件，无需编辑。
3. 双击 `安装环境.bat`，先选择 **1：安装 CPU 环境**，或 **2：额外安装 GPU 环境（CPU + GPU）**。安装器依次检查并导入图库、安装运行库和模型、自检、清理安装副产物。未放入图库时会先提示，不开始下载环境。
4. 双击 `启动.bat`，把显示的 `http://127.0.0.1:8765` 复制到浏览器，上传截图。按 Ctrl+C 停止服务，识别报告位于 `user/reports`。

首次准备需要联网；准备完成后可离线使用。只选择 CPU 即可运行全部识别功能。
GPU 环境独立安装，CPU 环境保留，模型和图库共用。关闭服务后重跑 `安装环境.bat` 并选择 2 可追加 GPU，无需重新放入图库或重装 CPU 环境。选择 1 不删除已有 GPU 环境。
GPU 安装按 NVIDIA 显卡和驱动自动选择 cu130 或 cu126；不满足要求会给出提示，不安装系统驱动或系统级 CUDA Toolkit。
额外 GPU 安装请预留至少 12 GiB 临时空间。GPU 自检失败时 CPU 仍可用。

## 下载与修复

普通 Python 依赖依次尝试华为云、清华、官方源；PyTorch 依次尝试国内镜像和官方源。
模型在已有对应文件的国内镜像上优先下载，没有对应镜像时使用官方源。
所有文件固定版本、大小和 SHA-256；镜像缺失或校验不符时尝试下一来源，不降低完整性要求。
下载窗口显示简要阶段和来源；大文件显示进度、速度和续传状态，小文件省略进度条。失败时可将原文件手动放到提示目录。

发布包只有 `安装环境.bat`、`启动.bat`、`修复.bat` 三个入口。
`修复.bat` 重新安装依赖并完整校验图库、模型和程序；损坏图库需重新下载 ZIP，放入 imports 后执行 `安装环境.bat`。
安装成功并通过自检后自动清理 `imports` 中本次使用的 ZIP、依赖 wheel、对应下载断点和安装临时状态；失败时保留供重试。
`imports` 外的原始下载不删除。用户报告、模型和识别缓存保留。
安装自检详情位于 `work/logs/install-check.log`，服务日志位于 `work/logs/server.log`。PNG 报告需要系统已有 Edge/Chrome；否则使用 HTML/JSON 报告。

## 目录与版本

- `app/v0.2.1`：推断程序和下载清单。
- `resources/gallery-20261009/data/images`：装备图片，保留有意义的文件名。
- `resources/gallery-20261009/data/indexes/head-dinov2` 等：按部位和模型命名的候选索引。
- `runtime`：内置 Python 和独立 CPU/GPU 运行库。
- `models`、`work`、`user`：基础模型、临时文件与缓存、用户报告。

安装器会对资源、暂存和依赖解压路径再次检查，绝对路径保守上限为 249 个字符。
64 字符预算适用于本次锁定的文件，第三方浏览器缓存仍建议使用短安装路径。
图库采集日期为 **2026-10-09**，与软件构建日期不同。

# FFXIV Prism v0.2.0 首次正式版

Windows x64 本地装备外观候选检索工具。无需安装 Python、Conda 或 Git。
输入清晰的单人角色截图，返回头、身体、手、腿、脚的装备候选；结果需要人工确认。

## 安装和使用

1. 下载 `FFXIV-Prism-v0.2.0-windows.zip`，完整解压到英文路径，例如 `D:\FFXIV-Prism`。安装根目录绝对路径最多 **64 个字符**（包括盘符和分隔符），不要在 ZIP 内运行。
2. 从维护者网盘下载本次重新构建的 `FFXIV-Prism-gallery-20261009.zip`，原样放入 `imports`。请用配套的 `.sha256` 校验文件核对下载。
3. 双击 `导入图库.bat`，选择 CPU 环境，或额外安装 GPU 环境。等待图库验签、运行库和模型下载、自检完成。
4. 双击 `启动.bat`，把显示的 `http://127.0.0.1:8765` 复制到浏览器，上传截图。按 Ctrl+C 停止服务，识别报告位于 `user/reports`。

首次准备需要联网；准备完成后可离线使用。只选择 CPU 即可运行全部识别功能。
GPU 环境独立安装，CPU 环境保留，模型和图库共用。关闭服务后重跑 `安装环境.bat` 可追加 GPU。
GPU 安装按 NVIDIA 显卡和驱动自动选择 cu130 或 cu126；不满足要求会给出提示，不安装系统驱动或系统级 CUDA Toolkit。
额外 GPU 安装请预留至少 12 GiB 临时空间。GPU 自检失败时 CPU 仍可用。

## 下载与修复

普通 Python 依赖依次尝试华为云、清华、官方源；PyTorch 依次尝试国内镜像和官方源。
模型在已有对应文件的国内镜像上优先下载，没有对应镜像时使用官方源。
所有文件固定版本、大小和 SHA-256；镜像缺失或校验不符时尝试下一来源，不降低完整性要求。
下载窗口显示来源、进度、速度和续传状态；失败时可将原文件手动放到提示目录。

`检查修复.bat` 完整校验图库、模型和运行库；损坏图库需重新下载并导入 ZIP。
安装成功并通过自检后自动清理 `imports` 中本次使用的 ZIP 和依赖 wheel；失败时保留供重试。
`imports` 外的原始下载不删除。用户报告、模型和识别缓存保留。
日志位于窗口和 `work/logs`。PNG 报告需要系统已有 Edge/Chrome；否则使用 HTML/JSON 报告。

## 目录与版本

- `app/v0.2.0`：推断程序和下载清单，不含训练脚本、实验记录、源码安装指南。
- `resources/gallery-20261009/data/images`：装备图片，保留有意义的文件名。
- `resources/gallery-20261009/data/indexes/head-dinov2` 等：按部位和模型命名的候选索引。
- `runtime`：内置 Python 和独立 CPU/GPU 运行库。
- `models`、`work`、`user`：基础模型、临时文件与缓存、用户报告。

安装器会对资源、暂存和依赖解压路径再次检查，绝对路径保守上限为 249 个字符。
64 字符预算适用于本次锁定的文件，第三方浏览器缓存仍建议使用短安装路径。
图库采集日期为 **2026-10-09**，与软件构建日期不同。

本次为首次正式发布，不提供 beta 升级包或兼容迁移。以前的测试目录不覆盖安装。
虽然网盘文件名保持不变，本次图库内容和 SHA-256 已改变，必须使用本次新包。

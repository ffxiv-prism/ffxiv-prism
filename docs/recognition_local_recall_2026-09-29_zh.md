# 局部视觉融合优化与独立测试（2026-09-29）

本次用通用的全局/局部连续评分替换之前的“保留前十、将一个候选插到第十一名”方案。没有装备 ID、装备名称、截图右侧文字或固定目标名次参与推理。基础视觉编码器与查询适配器权重没有重新训练；优化的是检索模型的多视图特征使用、召回范围和融合参数。

## 为什么会漏选

原报告 `data/outputs/web/c842d68e9c68/` 中，两件装备都在索引中。HEAD 主分支只使用头顶区域，眼部细节不足：血盟双剑师头巾在三个分支中分别为 612/610/633，融合后 655，官方同模去重及跨槽位过滤后 319。LEGS 腰至大腿的 DINOv2 检索已将正确外观排到 11，但 DINOv3 为 257；融合、固定候选池、风格重排及同模去重后为 24，超出报告的前二十。

输入图右侧文字只用于确认以上诊断的答案。该图没有进入参数选择或项目测试集。

## 模型改动

- HEAD 增加双眼关键点定位的左右眼区域。对完整头部装备库的所有可用渲染图统一裁剪左右眼，用零样本 DINOv2、SigLIP2 编码。先在候选眼部/渲染图/官方同模外观间取最高相似度，再转换为外观级排名。
- LEGS 用各折训练的 DINOv2 查询适配器编码腰至大腿、大腿两个区域，分别检索统一的候选大腿区域，每个视图检索 1000 个候选并按官方同模外观聚合。允许局部检索引入原融合候选池外的外观。
- 全部候选按 `1/(k+全局名次) + weight × gate × 局部倒数名次分数` 排序。HEAD 对模型分数取均值、查询眼部视图取最大值；LEGS 对两个查询视图取均值。没有前缀保护、每图补充数量限制或固定插入位置。
- `gate` 是图像描述分类的连续相对分数：HEAD 使用完整头部与脸部两个视图的眼部附件分数最小值；LEGS 使用两个视图的非长裤分数几何均值。它不是校准概率。姿态不可见、置信度不足 0.55、缺失局部图或原图截断时回退原检索。
- 眼部候选向量按图像内容、模型资产版本与预处理设置缓存。缓存不包含标签、答案或排名。仍执行官方槽位校验、官方同模合并、无装备判断及跨槽位规则。

主实现为 `matching/local_fusion.py`、`matching/local_retrieval.py` 和 `cli/match.py`；推理与评测共享分数组合、图像门控、同模聚合实现。默认 `current-best` 启用，`base` 不启用。原有下颌/耳侧细节分支仍存在；HEAD 的新连续融合在其后执行，因此它原来的前五保护不再是最终报告的保证。

## 参数选择与隔离

使用项目既有 `appearance-disjoint-cv-v55-slot-recovery-{head,legs}` 划分、冻结玩家样本、质量过滤和 `refresh_v110_*` 查询适配器。验证集采用各折对应适配器；测试集使用 fold-01 适配器和 manifest 的 `blind_test`，不是再从验证集抽样。

验证集 HEAD 共 927 张，LEGS 共 970 张。搜索 k∈{1,10,30,60}、weight∈{0.1,0.25,0.5,1,2,4}、3 种图像门控和 2 种视图组合，共每槽 144 组。目标为整体平均 log 名次 + 0.5×薄弱类别平均 log 名次，允许整体 Top-1/Top-10 各最多下降 3 个百分点。

薄弱类别在打开测试集之前用标签名称正则定义，仅用于计分：HEAD 为 `glasses|spectacles|goggles|eyepatch|blindfold|visor`，LEGS 为 `shorts|pantalettes|tanga|culottes|smalls`。这些是可复现的类别代理，不能覆盖所有眼部附件或短下装。

最终冻结参数：HEAD weight=0.5、k=10、eye_min、max；LEGS weight=0.5、k=60、exposed、mean。测试前参数文件 SHA256：`d44a571fe8b1c506441195c9ef2937623ef73f1e6af711f8db301064fa5ca3b6`。查看测试结果后没有改变模型或参数。脚本拒绝在已打开测试集的运行目录重新选择参数。

本机 Windows Conda 运行单元测试前需先初始化 NumPy BLAS；识别脚本和新评测脚本已包含该初始化。历史三折索引缓存可复用（检查 metadata、vectors、checkpoint 的 SHA256）；缺少缓存则重新编码。玩家图像、冻结划分、查询权重和评测资产须预先存在。首次眼部候选编码较慢，之后使用 `var/cache/eye-accessory-v1/`。

本次运行目录：`data/outputs/local-fusion-20260929/`。`HEAD/LEGS-selection.json` 保存每组参数结果，`locked-policy.json` 保存测试前冻结参数，`HEAD/LEGS-test.json` 保存逐图真实标签及优化前后名次，`*-validation.npz`、`*-blind_test.npz` 保存用于审计的特征排名与计分掩码。输出和大型资产为本地文件，不随代码上传。

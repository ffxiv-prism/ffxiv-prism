# 下颌和耳侧细节候选召回（2026-09-26）

报告 `data/outputs/web/55f42383be51/` 中的暴击 B2 头戴式拾音器，原 HEAD
Top-1000 检索池未召回。当前修复在正常 `current-best` 推理中将同模的暴击 B1
头戴式拾音器召回到第六名，同模列表包含 B2。原前五名保持不变。

## 原因及策略

此前下半脸框虽然覆盖拾音器，但眼睛、发型、脸部仍占据大部分图像。将三个既有
下半脸/耳侧框统一取下方 60%，能够保留嘴角、下颌及耳旁附件，减少这些干扰。
三个新区域命名为 `head_lower_face_detail`、`head_ear_left_detail`、
`head_ear_right_detail`。该比例来自本次开发样本的探索，后续验证固定该策略，
不把本例的结果当作独立泛化证据。

新区域保留父区域的置信度、可见性和截断标记。三个区域均须可见且置信度至少
0.55，才进入单独的 SigLIP2 零样本分支；现有训练查询适配器继续使用原头顶框。
候选侧复用当前活动 SigLIP2 全部 HEAD 多尺度索引，模型权重不变。

在检索前，使用固定八类视觉描述判断帽子、头盔、头顶饰品、眼部附件、面罩、
带话筒的耳机、耳侧饰品和裸脸。下半脸必须以至少 0.75 的相对分类分数支持
眼部附件/面罩/耳机/耳侧饰品之一，且至少一个耳侧视图以 0.5 支持同类。
这些分数是同一组描述下的相对分数，不是校准概率。没有按标签扫描阈值。

每个视图先过滤官方槽位并按官方同模关系去重。至少两个视图的 Top-1 为同一
外观，且第三个视图 Top-10 也支持该外观时，才补充一个候选：

- 已在前六名时不改动。
- 在更低名次时移动到第六名，并删除旧位置以避免重复。
- 不在原候选池时从独立分支补入第六名。
- 前五名逐项保留；多槽位一致性门禁仍在后续正常执行。

运行策略不读取装备名字、答案 ID、种族、染色或截图右侧文字。官方物品 ID
只用于索引返回结果、同模等价判断和报告展示。`--profile base` 不启用此分支。

本例生产路径的三视图支持排名为 1 / 6 / 1；这是同模去重后的排名。
最终五部位报告保存在 `data/outputs/recognition-head-detail-validated-20260926/`，诊断字段为
`head_detail_diagnostic`。最终显示顺序由策略决定，分支检索分数不是概率。

## 验证与适用边界

冻结三折使用各折原查询适配器的检索缓存，只编码新细节裁剪，不进行训练。
评测按官方同模关系计分；原注册 HEAD 指标仍对应旧基线，没有被此次局部召回
实验替换。独立分组结果保存在
`data/outputs/head-detail-evaluation-20260926/presence-evaluation.json`。

初始仅依赖检索投票的方案在 927 张样本中改排 688 张，Top-10 命中从 488
降到 485、Top-20 从 565 降到 558，已拒绝推广。原始结果保留在同目录
`evaluation.json`。大量裸脸局部会被零样本模型错误匹配到拾音器，说明两个
重叠区域的首位一致本身不足以确认附件存在。

最终存在性保护方案有 40 张通过类型门槛，其中 36 张发生改排。结果如下：

| 分组 | 样本 | Top-1 旧/新 | Top-10 旧/新 | Top-20 旧/新 |
| --- | ---: | ---: | ---: | ---: |
| fold 1 | 309 | 76 / 76 | 148 / 148 | 177 / 177 |
| fold 2 | 309 | 105 / 105 | 190 / 190 | 211 / 211 |
| fold 3 | 309 | 85 / 85 | 150 / 150 | 177 / 177 |
| 总计 | 927 | 266 / 266 | 488 / 488 | 565 / 565 |

两种模型性别、九个种族分组的上述指标均未改变。这是冻结候选快照下的回归检查，
没有观察到整体召回提升；也没有证明全部新增候选正确。部分真值的具体名次因插入
而后移一位，即使没有跨过 Top-10/20 截断。开发样本的拾音器成功进入前十，
不能用来宣称独立评测准确率提高。基线在官方同模去重后计分，分母和处理流程
与旧注册原始 piece 指标不同，不能直接横向比较。

该机制保留原 Top-5，但补入一个候选仍可能将原第十或第二十名挤出对应截断。
三个区域存在空间重叠，不能把一致票数当作独立概率相乘。极端侧脸、低分辨率、
头发遮挡和明显截断时会回退；不保证所有拾音器截图都能召回。

## 复现

```powershell
python scripts/recognize_glamour.py data/outputs/web/55f42383be51/input/source.png `
  --slots HEAD --device cuda --top-k 20 --output-dir data/outputs/head-detail-fixed-20260926
python scripts/evaluate_head_detail_recall.py `
  --output-dir data/outputs/head-detail-evaluation-20260926 --device cuda
python scripts/evaluate_head_detail_presence.py `
  --audit-dir data/outputs/head-detail-evaluation-20260926 --device cuda
python -m unittest discover -s tests
```

评测需要本机获授权的冻结玩家样本、姿态记录及三折检索缓存，这些不随代码提交。
修改裁剪、编码器权重或预处理时请使用新的评测输出目录。

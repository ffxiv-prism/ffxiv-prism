# 下颌与耳侧头饰裁剪验证（2026-09-24）

本次修复了本例拾音器被头顶/面饰框截掉的覆盖问题，但尚未解决最终身份识别。
新增裁剪已进入常规报告的质检输出；局部检索仍为独立实验，不替换默认 HEAD 排序。

## 原因与实现

输入是 `data/outputs/web/55f42383be51/input/source.png`。角色头部倾斜，拾音器主要
位于嘴角、下颌附近。现有 `head_upper_accessory` 的下边界为 y=436，
`head_face_accessory` 为 y=451，都没有完整包含关键细节。

新增三种通用视图：

| 名称 | 本例像素框（左、上、右、下） | 用途 |
| --- | --- | --- |
| `head_lower_face` | 545, 334, 784, 538 | 下半脸、嘴边、下颌附件 |
| `head_ear_left` | 653, 307, 838, 495 | 角色左侧耳部及邻近脸颊 |
| `head_ear_right` | 498, 345, 683, 533 | 角色右侧耳部及邻近脸颊 |

算法先用双眼连线建立局部横轴，用其法线表示脸部向下方向；面宽取双眼间距的
2.4 倍与可靠双耳间距的较大值。沿局部坐标定义区域后取轴对齐包围框，兼容现有
裁剪保存和报告流程。这是随倾斜调整范围，**不对图像旋转校正**。

尺度不依赖画布宽度、右侧文字或肩宽。人物缩放、平移、镜像、一定程度的歪头均使用
相同规则；装备名称、答案 ID、颜色、种族不参与裁剪。右侧文字只用于事后核对答案。

保护条件：

- 鼻尖、双眼或对应耳朵低于原有 0.35 姿态门槛时，标记姿态不确定。
- 双眼间距不足 1 像素时，不把眼线当作可靠方向。
- 双眼间距小于可靠双耳间距的 20%，或鼻尖沿眼线投影偏离眼中点超过一个双眼间距，
  标记 `foreshortened_face_geometry`。这只是近正面几何不适用的提示，不是识别出的装备类别。
- 希望覆盖的区域超出原图时，标记 `source_edge_truncation_risk`，保留截断提示。
- 三种视图均为 `diagnostic`，默认权重为 0；实验检索只使用可见且置信度至少 0.55 的视图。

## 本例检索实验

保持 SigLIP2 零样本编码器、原有多尺度候选索引及完整 HEAD 候选集合相同，
仅替换查询图，目标拾音器或官方同模物品的原始 piece 排名如下：

| 查询裁剪 | 排名 |
| --- | ---: |
| 原头顶框 | 1332 |
| 原面饰框 | 1076 |
| 原头部上下文 | 824 |
| 新下半脸框 | 190 |
| 新左耳侧框 | 413 |
| 新右耳侧框 | 522 |

这说明新裁剪改善了本例的小目标可见性和零样本候选召回，但 **第 190 名仍不足以
进入前 20，不能称为识别成功**。表中排名不是默认三模型融合结果，也没有与已训练
头顶查询适配器的指标混用。

另为全部 4,306 张 HEAD 展示图统一生成下半脸/双耳三个裁剪，得到 12,918 个
候选视图，涵盖 2,245 个 piece。该实验使用 `--head-crop-policy lower-face`，
查询与候选按同名视图匹配，再用既有 RRF k=1 融合。下半脸单视图目标排名反而降到
772，融合、同模去重后为 726。固定的人台局部框并未带来有效的匹配改善，因此
**未将此候选索引或融合方式接入生产配置**。

代码保留独立实验入口用于复现。没有按本图答案搜索融合权重，没有训练新适配器，
没有将正确物品强行置顶。将来若要参与默认排序，仍需使用与新局部视图匹配的训练和
独立身份评测，特别覆盖发型、侧脸、面饰、染色和不同种族。

## 回归检查

- 对 1,152 张历史姿态记录，与提交 `866eb855f8cb872257469a1fbb5c3e447d0deacc`
  中的裁剪实现逐项比较：所有原有区域的框、置信度、可见性、角色和标签均相同。
- 新增视图的默认检索权重全部为 0。
- 其中 1,034 张符合既有 HEAD 质量准入的图片，每种新视图均有 1,009 张标记可见、
  20 张姿态不确定、5 张部分可见。这是几何质量统计，**不是身份识别准确率**。
- 按九个种族和两种性别抽查可见样本中的较大眼线倾斜案例，保存 18 张局部图。
- 本例重新执行 CUDA 默认 HEAD 推理，筛选前 510 个候选与修改前逐项完全相同，
  仍只使用 `head_upper_accessory`。已有帽子检索行为没有因实验视图受到影响。
- 新增 12 项测试覆盖低位附件、旋转、平移缩放、镜像、画布留白、低置信度、极端侧脸、
  退化眼线、原图截断及默认配置隔离。全量 489 项测试通过，改动文件 Ruff 检查通过。

## 重放

在项目 Python 环境和现有完整数据缓存下执行：

```powershell
python scripts/evaluate_head_local_crops.py `
  --report-dir data/outputs/web/55f42383be51 `
  --output-dir data/outputs/head-crop-audit-20260924 `
  --truth-piece-ids 911 --device cuda
python -m unittest discover -s tests
```

`--truth-piece-ids` 可省略；只用于检索完成后的计分，脚本会扩展官方同模物品。
首次会构建独立候选索引，后续验证缓存合同后复用；不得把输出目录设为原报告目录。
改变候选图片、模型权重或候选预处理时应使用新的索引目录。

证据目录 `data/outputs/head-crop-audit-20260924/`：

- `crop-comparison.jpg`：旧头顶框、旧面饰框、新下半脸框对照。
- `head-crops.jpg`、`regions.json`：八种 HEAD 视图及精确几何信息。
- `results.json`、`query-only-candidates.json`：局部候选实验和原索引查询对照。
- `report.html`：未推广的候选局部裁剪实验报告，不能当作默认识别结果。
- `geometry-audit.json`、`head-geometry-gallery.jpg`：历史区域一致性和跨种族质检。
- `default-runtime-parity.json`：默认生产推理候选一致性证据。

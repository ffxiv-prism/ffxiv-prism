# v47 严格折内查询困难负样本结果（2026-07-04）

## 结果

v47 按预注册配置完成三个 v44 BODY-item-disjoint 折。查询编码器只增加
`hard_negative_weight=0.2`、`K=20`、`margin=0.5`，其余配置保持冻结。

| 阶段 | v44 Top-1 / Top-10 / Top-100 | v47 Top-1 / Top-10 / Top-100 | 变化 |
|---|---:|---:|---:|
| 查询编码器 | 293 / 577 / 825 | 307 / 588 / 829 | +14 / +11 / +4 |
| 重新训练的重排器 | 365 / 676 / 847 | 361 / 660 / 846 | -4 / -16 / -1 |

最终逐折变化：

| 折 | v44 Top-1 / Top-10 | v47 Top-1 / Top-10 | 变化 |
|---|---:|---:|---:|
| 1 | 127 / 234 | 119 / 228 | -8 / -6 |
| 2 | 128 / 226 | 131 / 223 | +3 / -3 |
| 3 | 110 / 216 | 111 / 209 | +1 / -7 |

按性别的最终结果：

| 性别 | v44 Top-1 / Top-10 | v47 Top-1 / Top-10 | 变化 |
|---|---:|---:|---:|
| Female，607 例 | 250 / 456 | 250 / 448 | 0 / -8 |
| Male，299 例 | 115 / 220 | 111 / 212 | -4 / -8 |

配对比较为 39 个 v47-only Top-1 胜例，对 43 个 v44-only 胜例；Top-10 为
17 个新增、33 个丢失。

## 决策

v47 不晋级。它未满足 pooled Top-1、Top-10 同时提高，也出现男性域退化。

但查询编码器本身在三个折的 Top-1 都提高，并且 pooled Top-1、Top-10、Top-100
全部提高。这支持保留“查询困难负样本”作为有效表征改进，同时停止使用本轮重新训练的
重排器。下一实验只验证改进查询与冻结 v44 重排器的兼容性。

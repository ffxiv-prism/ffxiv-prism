# beta.2 启动与下载改进验证

本次保持识别代码、基础模型、Python wheel 版本和图库兼容标识不变。

## 改动

- 四个 BAT 在启动 Python 前显示操作名称，使用无缓冲输出，并保留失败退出码。
- 启动器显示 ZIP 扫描、签名验证、解压、依赖安装、模型检查、自检和 Web 启动阶段。
- 依赖和模型共用下载进度：百分比、已下载/总 MiB、速度、预计剩余时间、来源网址、
  实际重定向网站、连接超时、重试及换源提示；日志重定向时采用周期性整行输出。
- 本地缓存和下载后 SHA-256 校验有进度；完整的 `.part` 可直接校验恢复，
  短响应保留已下载内容继续续传。服务器忽略 Range 时从头下载。
- 38 个 PyPI wheel 增加华为云、清华镜像。两个 PyTorch 仓库文件仍使用原官方源。
  新运行环境 ID 与下载来源清单一致；wheel 文件名、大小和 SHA-256 均未改变。
- Windows 安全扫描导致暂时占用解压文件时，安装目录切换短暂重试。
- 构建器发现原签名私钥缺失时终止，不再意外生成新密钥覆盖公钥。

## 已验证

- 完整标准库测试：579 项通过，包含 8 项新增下载与镜像回归测试。
- 四种 BAT 通过真实 `cmd` 执行验证：立即输出状态，缺少内置 Python 时明确报错且返回 1。
- 76 个新增镜像地址全部通过 HTTP HEAD 检查。
- 同一个固定 wheel 从 PyPI、华为云、清华真实下载，均通过原始 SHA-256 校验。
- DINOv2 配置文件从 Hugging Face、魔搭真实下载，均通过原始 SHA-256 校验。
- 模拟验证换源、续传、忽略 Range、短响应、错误 Range、哈希失败和完整本地缓存恢复。
- 在独立目录中复用旧下载缓存，实际校验并安装全部 40 个 wheel；官方嵌入式
  CPython 3.12.10 成功加载 NumPy、torch 2.11.0+cpu、transformers 5.12.1，
  CPU 矩阵运算通过，没有使用 Conda 依赖执行该运行验证。

## 发布与升级约束

基础权重大文件未从每个来源重新下载，所有来源的文件校验仍强制执行。
新签名包的完整安装验收需原 `work/signing/portable-private.xml`。
此记录不代表新 release 包已签名或发布。

beta.1 的 app 更新包不覆盖根启动器。升级 beta.2 时需先从完整 windows ZIP 更新
`bootstrap`、四个 BAT 和使用说明，再导入新 app ZIP；步骤见
[便携版使用说明](portable_release_zh.md)。图库继续使用 `gallery-20260926-head-v2`。

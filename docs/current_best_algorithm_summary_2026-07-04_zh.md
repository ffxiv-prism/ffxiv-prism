# 当前最佳装备识别算法技术路径摘要（2026-07-04）

## 一、结论先行

当前项目真正可比较的“最佳结果”有两条，必须分开理解：

| 评估目标 | 当前最佳方案 | Appearance Top-1 | Appearance Top-10 | 结论 |
|---|---|---:|---:|---|
| 混合/可能见过同一装备的部署场景 | qv52 查询编码器 + v35 重排器 + v2 候选索引 | 55/81，67.9% | 72/81，88.9% | 当前部署默认方案 |
| 完全未见过目标装备的严格泛化 | v44 数据，折内从基础 DINOv2 重新训练查询编码器和重排器，v3 多尺度索引 | 365/906，40.3% | 676/906，74.6% | 当前最可信的未知装备研究基线 |

这里的指标已经按外观等价（appearance equivalence）计分：返回精确物品，或返回确认属于同模外观的装备，都算识别成功。

现阶段尚未达到 80% 目标。67.9% 是当前最好的实际部署参考值，但它不是“对完全未知装备”的无偏估计；40.3% 才是严格物品不相交条件下的端到端结果。此前出现过的 62.5% 严格折结果复用了全量训练过的 qv52，因此查询编码器已经见过部分留出装备，只能作为重排能力诊断，不能当作未知装备准确率。

另外，当前成熟指标只覆盖 `BODY`（上衣/躯干部件），还不是 HEAD、BODY、HANDS、LEGS、FEET 五个槽位的总体单部件准确率。

## 二、当前部署最佳方案：qv52 + v35 + v2

整体流程为：

```text
带真实装备标签的玩家搭配图
  → 高质量正面全身图筛选
  → 人体姿态估计与 BODY 多区域裁剪
  → qv52 将玩家图裁剪编码为视觉向量
  → 在标准装备渲染图索引中召回前 1000 个候选
  → v35 对“玩家图裁剪—候选装备图”逐对非线性重排
  → 多裁剪按固定规则融合
  → 按精确装备或同模外观计算 Top-1 / Top-10
```

### 1. 数据与标签

- 训练和评估标签来自 Eorzea Collection 页面中的真实 FFXIV 装备字段，不使用视觉模型猜测物品 ID。
- 训练图只纳入经过姿态规则和人工复核的高质量正面/近正面全身图。
- v35 重排器使用的 v40 质量清单包含 696 张通过审核的图片。
- 训练样本按 `glamour_id` 聚合，避免同一套搭配的多张相似图片被当作彼此独立的样本而放大权重。

### 2. 玩家图区域提取

系统使用人体关键点生成三个 BODY 观察区域：

- `body_torso`：躯干主体，尽量集中于上衣本身；
- `body_upper_arm_overlap`：包含上臂和袖子，用于长袖、护臂与上衣边界模糊的情况；
- `body_context`：更宽的上下文区域，保留肩部、腰部等有助于判断整体轮廓的信息。

推理时采用固定的 `balanced / none / max` 融合规则：主体区域权重 1.0、辅助区域 0.78、上下文区域 0.72，再乘以可见性和姿态置信度；不额外施加标签惩罚；同一装备在多个查询裁剪中的最高分作为最终证据。

**ViTPose**：人体姿态估计模型，通过肩、肘、腕、髋、膝、踝等关键点定位人物和装备区域。它负责“裁哪里”和质量辅助判断，不负责识别具体装备。

### 3. 标准装备候选索引

v2 候选索引包含：

- 19,721 张标准装备源渲染图；
- 27,057 个槽位对齐后的候选视图；
- 每个候选为 768 维 DINOv2 向量；
- BODY 候选使用标准渲染图的 `upper_body` 裁剪，减少腿部、背景和无关人体区域干扰。

**向量检索**：把玩家图和候选装备图都表示成定长向量，用余弦相似度快速找出视觉上最接近的候选。它负责高召回的第一阶段筛选。

### 4. qv52 查询编码器

qv52 以 `facebook/dinov2-base` 为骨干，只微调最后一个 Transformer block，约有 709 万个可训练参数；输出 768 维、经过归一化的查询向量。它从 qv51 继续训练，并保留以下关键设置：

- 彩色输入和常规图像增强；
- 按搭配组聚合多张视图；
- 每个 BODY 样本最多使用 3 个裁剪；
- 多正样本对比损失；
- 20 个困难负样本，权重 0.2，间隔 0.5；
- 温度系数 0.07；
- 不使用 foreground 替代图作为默认训练输入。

多视图训练使用 log-mean-exp 聚合：同一搭配的多张图共同提供证据，但不会因为图片数量更多就天然获得更大权重。

**DINOv2**：Meta 提出的自监督视觉表征模型，不依赖文本提示也能学习形状、纹理和部件结构。这里用它缩小“玩家截图”和“标准装备渲染图”之间的视觉域差异。

**对比学习**：让查询图向正确装备向量靠近、远离错误装备向量。多正样本版本允许同一标签对应多个标准视图或同模装备。

**困难负样本挖掘**：训练时重点加入“看起来很像但其实错误”的装备，迫使模型学习袖型、领口、甲片等细粒度区别，而不是只学颜色或大轮廓。

### 5. v35 非线性成对重排器

第一阶段先按向量相似度召回前 1000 个候选，v35 再逐对计算更精细的匹配分数。每一对的输入特征包括：

- 查询向量与候选向量的逐维乘积；
- 两个向量的逐维绝对差；
- 余弦相似度；
- 16 维槽位嵌入。

模型使用一个 256 → 128 的小型 MLP 学习非线性残差，并叠加可学习缩放后的余弦分数。模型约 43 万参数，dropout 为 0.1；按搭配组训练 7 个固定 epoch，学习率 0.001，每个样本使用最多 1000 个困难候选。

**非线性重排器（reranker）**：第一阶段只看通用向量距离，重排器进一步学习“两个视觉向量在哪些维度上一致或冲突”，适合纠正高相似候选之间的顺序。

在固定公开验证集上，单纯余弦召回为 37/81（45.7%）Top-1、60/81（74.1%）Top-10；经过 v35 重排和固定裁剪融合后达到 55/81（67.9%）Top-1、72/81（88.9%）Top-10。也就是说，重排器净救回了大量本来排在第 2～10 位甚至更后的正确候选，是当前方案中贡献最大的后段模块。

### 6. 同模装备计分

评估时优先用页面解析得到的精确 `piece_id` 集合匹配，同时通过规范化外观名和已构建的外观等价关系识别同模装备。因此：

- 精确物品命中：成功；
- 已确认同模、但名称或物品 ID 不同：Appearance 指标中也算成功；
- 只是在视觉上相似、没有等价证据：不算成功。

**外观等价关系**：把共享同一模型外观的不同职业版、强化版或名称变体连接起来，避免把“模型完全相同但物品 ID 不同”错误计为失败。

## 三、严格未知装备最佳方案：v44 端到端三折

严格方案的主体结构与部署方案相同，但评估规则更苛刻：

1. 按 BODY 装备身份把数据拆成三折，同一装备的全部搭配图只能存在于一个折；
2. 每一折都从基础 DINOv2 重新训练查询编码器，不能复用见过留出装备的 qv52；
3. 查询编码器固定训练 10 个 epoch；
4. 重排器固定训练 7 个 epoch，并使用 1000 个困难负样本；
5. 使用 v3 多尺度候选索引，同时保留 `upper_body` 和更紧的 `torso_core` 标准图裁剪；
6. 继续使用冻结的 `balanced / none / max` 推理配置；
7. 三折汇总，并检查男女域以及每一折是否退化。

**物品不相交交叉验证（item-disjoint CV）**：测试折中的装备身份从未出现在该折的训练数据中，用来估计系统面对新装备时的真实泛化能力，比普通图片随机划分严格得多。

v44 在三折 906 个案例上达到：

- Appearance Top-1：365/906，40.3%；
- Appearance Top-10：676/906，74.6%；
- 三个折都比配对的 v43 数据基线提高；
- 相比 v43，Top-1 增加 9 个案例，Top-10 增加 12 个案例。

后续 v45、v46 虽扩大了数据，但收益很小且伴随男女域此消彼长或 Top-10 下降，所以没有替代 v44 作为严格研究基线。

## 四、当前主要瓶颈

1. **候选表示和召回仍是首要瓶颈。** 严格未知装备 Top-10 为 74.6%，说明相当一部分正确外观在前十中根本不存在，单纯继续调最终排序规则无法把 Top-1 推到 80%。
2. **qv52 的强结果有“见过装备身份”的收益。** 从严格端到端 40.3% 到部署 67.9% 的巨大差距，说明当前表示对已见装备记忆较强，对真正新装备的迁移不足。
3. **玩家截图与标准渲染图存在明显域差异。** 姿态、染色、光照、种族体型、性别版型、遮挡和背景都会改变视觉特征；目前只微调最后一个 DINOv2 block，适配能力可能不足。
4. **候选端视角覆盖有限。** v2 每件 BODY 主要使用上半身单尺度标准图；v3 的紧致躯干裁剪能改善未知装备召回，但仍没有真实穿着图、多角度或跨种族/性别的完整候选原型。
5. **数据域仍不均衡。** 后续单性别扩充已表现出一个域上升、另一个域下降的专门化现象，继续简单堆数据不一定稳定提高总体泛化。
6. **当前成果仅能代表高质量 BODY 图。** 若目标扩展到全部五个装备槽位，小部件可见像素、遮挡和槽位间重叠会使难度显著增加。

## 五、下一阶段最值得先做的事

下一步应先在冻结的严格三折协议内测量四级漏斗：

```text
真值是否存在于候选索引
  → 基础 DINOv2 能否召回
  → 微调查询编码器能否召回
  → 正确候选进入候选池后，重排器能否把它转成 Top-1
```

这个诊断能把问题明确归到“索引覆盖、视觉表示、候选召回、最终排序”中的一层。之后只预先声明一个改进配置，在全部三折上验证；晋级条件应同时要求 pooled Top-1、Top-10 提升，至少两折不退化，且男女域没有实质性下降。公开验证集只在严格候选通过这些守门条件后使用一次，盲测池继续封存到接近最终目标时再开启。

就现有证据看，最可能产生实质收益的方向不是继续调路由阈值，而是：

- 增加候选端跨性别、跨种族和多尺度视图；
- 训练更强的截图—标准渲染域对齐目标；
- 在保持物品不相交的前提下，显式抑制性别/种族域特征；
- 针对召回失败与“已召回但未排第一”分别设计损失和采样策略。

# v50 预注册实验：低学习率短程 warm-start 重排（2026-07-04）

## 假设

v47 从零训练 7 epoch 的新重排器抵消了困难负样本查询的收益，而 v48 直接复用旧重排器
得到小幅稳定提升。这说明旧重排器已经具有有用的细粒度边界，但与新查询向量仍有轻微
分布偏移。

本实验从各折 v44 重排器初始化，仅在 v47 查询向量上用十分之一学习率短程适配：

- 初始化：对应折 v44 重排器；
- 查询：v47 hard-negative 查询检查点；
- epoch：固定 2；
- 学习率：`2e-5`（基线从零训练为 `2e-4`）；
- 其余训练与评估配置保持 v48 不变。

该配置旨在保留旧边界，仅修正查询分布偏移。只测试这一组 epoch/学习率，不做外层折
搜索。

## 晋级条件

相对 v48（369/906 Top-1，679/906 Top-10）：

1. pooled Top-1 和 Top-10 同时提高；
2. 至少两个折 Top-1 不退化；
3. male 和 female Top-1 均不出现实质性退化。

本文件在三个 v50 结果生成前冻结。
